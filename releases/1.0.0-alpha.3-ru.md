## A. Открытие после сканера — причина и фикс

Alpha.2 меняла только частицы скана. Это **не** анимация открытия.

Доказанная цепочка (без свежих логов после alpha.2, по коду и регрессионным тестам):

1. Dest-чанки и IP-портал поднимались только на **ГОТОВО** (`ScanReveal.start` → `spawnReveal`). До этого renderer назначения часто ещё не скомпилирован → непрозрачная воронка сразу после «ГОТОВО».
2. `start()` всегда делал despawn+respawn той же пары, сбрасывая уже собранный dest.
3. Часы iris шли по **wall-time**, пока dest был не готов. Как только dest появлялся, `iris` мог сразу стать 1.0 → резкий/шумный Nether вместо плавных 2 с.
4. Дыра iris вырезала целые тексели воронки (`vortexSubdiv` на большом окне = 1 квад на блок) → зубчатая кайма.

Что сделано:

- Preload IP+chunk loaders в начале дешифровки; на COMPLETE та же пара **не** despawn/respawn.
- Iris считает только готовое время: пока dest не готов — воронка; после готовности — 2 с ease open; flicker снова кроет воронкой, не rewind и не прыжок к 1.0; 2 с close в конце 60 с.
- Fallback «только центр dest скомпилирован»: 100 → **20** тиков.
- Пока iris движется, subdiv отверстия мельче (`irisSubdiv`), чтобы кайма не пилила квадратами.
- Без IP iris остаётся 0: честная непрозрачная воронка.
- Только сканирующий клиент получает payload; остальные всегда видят воронку.
- IP-адаптер по-прежнему view-only, `teleportable=false`. Чужой mixin-crash official IP 6.0.7 + Sable 2.0.6 не трогали.

## B. Спавн по утверждённому макету v4

Одноразовый (не цикл GIF). Оба конца пары. `elapsed = total - remaining` — chunk reload / late join **продолжает**, старые порталы без forming-часов **не** проигрывают заново.

Порядок:

1. Короткая visual-only молния (без огня/урона/разрушения блоков; entity-молния только `visualOnly`, если `openingLightning`).
2. Центральный зародыш.
3. По очереди UL → UR → LR → LL: точка вылетает из центра, линии уже соединяют и **растягиваются** во время движения.
4. LL — это сам зародыш, уходит в угол; пятой точки в центре нет.
5. Маленькая рамка плавно растёт до **фактических** width×height пары (unstable / standard / massive как в текущем конфиге, без новых чисел и без переименования классов).
6. Непрозрачная воронка / финальный портал. Пока `FORMING` — телепорта нет (и AeroPortals `resolve` тоже `null`).

Гул 128 из alpha.2 не менялся. Размеры классов не менялись. Логотип / прочий backlog — нет.
