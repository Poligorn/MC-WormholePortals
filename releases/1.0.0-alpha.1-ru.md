# Wormholes 1.0.0-alpha.1 — заметки (не стабильный релиз)

Версия Maven/NeoForge: **1.0.0-alpha.1** (это запрошенный 1.0-alpha.1: пререлиз 1.0.0, новее 0.6). Не merge / tag / publish.

## Установка

1. Заменить старый `wormhole-portals-0.6*.jar` на `wormhole-portals-1.0.0-alpha.1.jar` в `mods/`.
2. Minecraft **1.21.1**, NeoForge **`[21.1.235,)`**.
3. Cloth Config нужен только если ставится Immersive Portals.

## Что исправлено в этой альфе

- Вернулся **гул** живого портала (looping drone). В 0.6 троттлинг частиц на больших окнах заглушил старые редкие one-shot `PORTAL_AMBIENT`. Звук гаснет при collapse / смене измерения.
- After scan: live destination **только сканеру, 60 с**, плавное **2 с** открытие и закрытие. Воронка непрозрачна, пока dest-чанки не скомпилированы; оверлей после IP, чтобы не было резкого шумного Незера вместо iris. Destination доходит до белой кромки 0.03. Часы клиента не зависят от `gameTime` измерения.
- Dedicated server больше не тянет клиентские классы IP в общем адаптере.
- Утверждённый вид без редизайна: непрозрачная пиксельная воронка, белая constantly-bright кромка 0.03, глубина/halo, миниатюра анализатора как была.

## Зависимости и совместимость

| Сборка | Live-вид после скана | Корабли Aeronautics |
|---|---|---|
| Только Wormholes | Нет (непрозрачная воронка) | Нет |
| Wormholes + IP 6.0.7 + Cloth, **без Sable** | Да (view-only, `teleportable=false`) | Нет |
| Wormholes + AeroPortals 1.3.6 + Sable 2.0.6, **без official IP** | Нет | Да (наш публичный адаптер) |
| Official IP 6.0.7 **и** Sable 2.0.6 вместе | Не поддерживается: crash при старте (чужой mixin). Мы это **не** чиним своим JAR и не ставим форки. | |

Бесшовный телепорт через IP и «реальный полёт корабля» — бэклог, не эта альфа. Текущий IP-адаптер **не** заменяет перенос Wormholes/AeroPortals.

## Чеклист ручного плейтеста (нужен GUI-клиент)

1. Подойти к живому порталу: слышен гул; после dying/удаления гул исчезает.
2. Скан с IP+Cloth (без Sable): воронка держится, пока dest не готов, затем 2 с iris; Nether без «шумной каши»; кромка белая, dest доходит до неё; через 60 с 2 с закрытие, воронка возвращается.
3. Второй игрок (если есть) видит только воронку, без чужих IP-дыр.
4. Без IP: после скана воронка непрозрачная, как раньше.
5. Проход игрока Overworld↔Nether по-прежнему наш телепорт, не IP.
6. Логаут / релог: нет зависших IP-сущностей и вечной воронки-оверлея.

## Заведомо не в этой альфе

- Подтверждённый перелёт корабля Aeronautics (размеры 16–50 в коде есть; полёт в игре не обещаем).
- Конфликт IP+Sable.
