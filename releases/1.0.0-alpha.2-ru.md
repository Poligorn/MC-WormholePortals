## Установка

1. Заменить `wormhole-portals-1.0.0-alpha.1.jar` на `wormhole-portals-1.0.0-alpha.2.jar` в `mods/`.
2. Minecraft **1.21.1**, NeoForge **`[21.1.235,)`**.
3. Cloth Config нужен только если ставится Immersive Portals.

## Что исправлено в этой альфе

- **Гул на 128 блоках.** Vanilla `block.portal.ambient` имеет `attenuation_distance` 16, OpenAL LINEAR обнуляет громкость на 16 блоках. Теперь играет свой `portal.hum` (сырой `minecraft:block/portal/portal`, attenuation 256) и квадратичный спад: полный рядом (≤8), тишина на дистанции из конфига (`audio.ambientHearDistance`, по умолчанию 128, диапазон 100–150, фактически `min(это, renderDistance*16)`). Направление сохраняется. Один луп на окно; стоп при collapse / другой мир / логаут. Nested IP не включает гул назначения и не рвёт исходный.
- **Live-вид после скана.** `ScanRevealClient` больше не ссылается на `ImmersivePortalsClient` напрямую (qouteall грузится только если IP есть). Dest renderer берётся через `getWorldRenderer`, а не `WORLD_RENDERER_MAP.get`. Часы радужки по-прежнему клиентские тики.
- **Сканер ПКМ по порталу.** Во время дешифровки на кликнутый frame сыпались vanilla `ParticleTypes.PORTAL` (спрайты адского портала) — на старте скана, после него и при повторном нажатии. Теперь это спирали червоточины из центра окна. HUD анализатора и BER воронки не менялись.
- Размеры классов порталов **не** менялись.
- Анимация спавна **не** в этой альфе.

## Зависимости и совместимость

Как в alpha.1: official IP 6.0.7 + Sable 2.0.6 по-прежнему чужой mixin-crash. IP-адаптер view-only, `teleportable=false`.

## Чеклист ручного плейтеста (нужен GUI-клиент)

1. Гул слышен далеко (ориентир 100–128 блоков при достаточном render distance), рядом не оглушает, направление есть, после collapse/логаута/смены мира тишина.
2. Скан с IP+Cloth (без Sable): воронка держится, пока dest не готов, затем 2 с iris.
3. ПКМ сканером по порталу: на воронке нет спрайтов ванильного адского портала в начале скана, после него и при повторном клике.
4. Без IP клиент стартует; после скана воронка непрозрачная.
